# 🐈 Summa
**Summa** é um software **open source** desenvolvido em **Python**, criado para gerar **resumos automáticos de vídeos do YouTube** utilizando a Tecnologia **Gemini**.

![summa](https://github.com/user-attachments/assets/6f5a56b3-be70-4911-b9f5-894493a0209c)

## 🛠️ Tecnologias Usadas
- Linguagem: **Python**
- Interface: **CustomTkinter**
- Imagens: **PIL**
- Transcrição: **YoutubeTranscriptApi**
- Criar Resumo: **genai**
- Outros: **webbrowser, threading, dotenv**

## 🚀 Como Instalar
```bash
git clone https://github.com/rafssunny/Summa.git
cd Summa
python main.py
```
## 📌 Como Usar
1. Crie um arquivo .env com a sua Key
```
  GENAI_API_KEY="YOUR KEY"
```
2. Abra o programa.
3. Cole o link do vídeo seguindo o modelo especifico no programa.
4. Aperte Enter.
5. Se quiser, copie o resumo gerado apertando em copiar.
